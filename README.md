# 柚子 · 初一上数学期末备考站

面向 **北师大实验中学（西城）初一上期末** 的静态备考站。纯 HTML/CSS/JS，无 CDN、无外链、断网可玩，`file://` 双击直接打开。

**当前规模**：6 章 · 23 张方法卡 · **367 题** · 50 张概念卡（153 个判断）· 46 条公式法则 · **39 页（6 主页面 + 23 方法卡 + 6 章节页 + 首页等）** · **4 份真题（4 个学年）的逐题分析** · **27 个考点族全覆盖**（367 题全部归族，0 遗漏，且每族都有讲解）。

完整规划见 [PLAN.md](PLAN.md)；**真题分析的方法论（可复制到其他学科/学段）见 [METHOD-真题分析.md](METHOD-真题分析.md)**。

## 这个站与「中考备考站」的根本差异

参考项目 `bj-math-site` 回答的是「看到题不知道用哪个方法」。初一上期末的主要矛盾不同：

| | 中考站 | 本站 |
|---|---|---|
| 主要失分 | 方法不会（压轴想不到辅助线） | **会做但算错、写不全、审不清** |
| 主线 | 方法卡 | **计算自动化** |
| 分层 | 送分/中档/区分（按卷面分值） | **熟练/理解/攻坚**（按认知要求） |
| 熟练层达标线 | 90% | **98%** —— 一道 5 分解方程错个符号就是 0 分，没有部分分 |
| 错因 | 五类（含「构造」） | **六类（把「符号错误」单独拆出）** |
| 首页 | 产品介绍 | **今日任务卡** —— 打开就能做 |
| 判分 | 只判终结答案 | **分步判定** —— 初一的计算路径唯一，可以判到步 |

> 一句话：**初一提分靠「减少非受迫性失误」，不是靠「多会几道难题」。**

## 卷面口径（两套模板）

**主轨 · 西城区期末卷**（多份同卷文档摘要逐字一致）：

```
6 页 · 两部分 · 四道大题 · 26 道小题 · 100 分钟
必做满分 100：选择 8×2=16 / 填空 8×2=16 / 解答约 10 题 68 分
第四大题：选做 10 分，计入总分，但卷面总分不超过 100
```

**这条「封顶」规则改变策略**：必做卷丢 5 分，选做全对也只能回到 100——丢分补不回来。所以**基础零失误比押中压轴更值钱**。

**副轨 · 北师大实验自命题**（备用，本校有加试传统）：2019 期中为 100+20 分 / 27 题 + 3 道附加题 / 100 分钟，题量更大、压轴更难。

> 注：校内《初一上期中复习指导说明》给的「10 选择 + 10 填空 + 10 解答」是**期中校卷**口径，与期末区卷不同，两者并存不矛盾。站内已做成双口径，共用同一份知识清单。

## 三层（按认知要求，不按分值）

| 层 | 目标 | 训练方式 | 目标线 | 满分要求 |
|---|---|---|---|---|
| **熟练层** L1 | 会做的必须做对 | 限时计算 + 分步判定 + 连对计数 | 98% | **100%** |
| **理解层** L2 | 知道为什么，能列式 | 概念条件判断 + 应用题建模 | 90% | **100%** |
| **攻坚层** L3 | 拿到能拿的分 | 方法卡 + 分层提示 + 采分点自评 | 50% | **95%** |

> **两列必须分开看。** 目标线是「不拖后腿」，满分要求是「够满分」。只看目标线会得出「L3 已达 50%，压轴过关」的错误结论——实际离满分还差一半。诊断页现在两档并排显示。

## 每日闭环（45 分钟，顺序不可调）

```
① 闪测 5′   概念条件判断 ×8（只考条件不考背诵）
② 计算 15′  限时计算 ×10（分步判定，记录「会做但错」）
③ 主题 15′  当日主题（方法卡 / 应用题 / 压轴）
④ 错题 10′  今日与到期错题重做
```

顺序有理由：计算需要清醒的注意力，放在闪测之后、主题之前；主题练习需要先「热起来」。

**时间不够时优先砍「主题」段，不要砍计算和错题。**

## 排序与回流（2026-11-24 新增）

站内三套坐标系原先互不相通：真题分析按「考点族」（27 个，有分值频次）、练习按「方法卡/章节」、诊断按「错因/第几步」。结果诊断说「几何偏弱」，落不到「角度推理 19 分、3 年考」；真题说「压轴 26 分」，点不进去练。

**族标签层**（`src/data-family-map.js`）把三者焊在一起：367 道题全部归属到 27 个族之一，`validate.mjs` 有四条硬断言（每題恰属一族 / 每族 ≥2 题 / 阶梯锚定族有题 / 映射表无残留键）。

### 排序：两步，不是单一分数

**第一步 定档（硬规则，不看数值）**

| 档 | 判据 | 理由 |
|---|---|---|
| P0 | 熟练层（l1）族 | 必做段丢分不可补，且训练成本最低 |
| P1 | 4/4 年考且年均 ≥5 分的中档族 | 路径确定 |
| P2 | 其余中档族 | 值得练，不构成满分瓶颈 |
| P3 | 攻坚层（l3）族 | 只求入场分，投入产出最慢 |
| P4 | 少见族（<2 分/年且非年年考） | 时间充裕才碰 |

**P0 没全达标，P1 不启动。** 这是「先基础后压轴」的制度化。

为什么不用「可回收分」单值排序：压轴（8.3 分/年 × 80% 失分 = 6.6）会排在计算（18 × 5% = 0.9）前面。算得对，结论错——6.6 分里没有一分能在两周内稳定拿回来。单值公式补不上这个，因为「压轴训练成本是计算的 4 倍」没有数据来源。

**第二步 档内排序**：`可回收分 = 年均分 × 失分率 × 可回收系数`。l3 系数 0.4 从 `FAMILY_MAP[].slots` 反推（压轴 6–7 分整题，入场分约 2.5–3）。

**族的分层用站内题分布，不用真题难度标签**：真题的 `mid` 只表示「这是解答题」。有理数四则混合运算是 mid，但认知要求是自动化（熟练层），该用 98% 门槛而非 90%。

### 回流：三态状态机 + 当日快照

| 状态 | 判据 |
|---|---|
| 未测 | 有效作答 < 3 题。不参与失分率计算，但仍在清单里 |
| 训练中 | 有记录、未达阈值 |
| 已达标 | 达阈值；不是消失，转为低频复习（1→2→4→8…天） |

**达标阈值（分层不同）**

| 层 | 判据 | 理由 |
|---|---|---|
| l1 | 最近 ≥10 题 ≥98% **且**跨题连对 ≥3 | 98% 是零失误的可操作近似；连对必须跨题 |
| l2 | 最近 ≥8 题 ≥90% | 选填错一题丢 2 分 |
| l3 | 最近 ≥5 题 ≥50% | 入场分口径，不是「压轴过关」 |

l1 的双门槛不能简化成一个：只卡正确率，10 题错 1 题在末尾也算过（那是「刚学会」）；只卡连对，错 5 题后连对 3 次也能过（样本太小）。

**退化规则**：已达标后错一次即退回训练中。和变式阶梯「错一级重置」同一原则——防止靠运气凑过门槛。

**当日快照**：清单一天只算一次，每题之后不重算。理由：清单一直跳会让学生无法形成「今天做完这几件」的认知。

### 闭环实测

`tools/e2e-family.mjs` 用真实浏览器验证 14 项：档位有序、首条是熟练层、冷启动显示「未测」、L1 答对 10 题达标、达标后移出清单、错一次退回训练中、nearMiss 高切「限时收尾」、快照复用同日、P0 全排在 P3 之前、分片里 382 题全带 family。

## 能力维度诊断

知识点维度回答「哪里弱」，能力维度回答「为什么弱」。两者需要不同的数据。

### 能力四维与判据

| 能力 | 判据来源 | 补救动作 |
|---|---|---|
| **执行** | 「改数字」级变式错 / 最后一步错 | 限时重复，不讲方法 |
| **条件** | 「改条件」级变式错 / 卡在第 1–2 步 | 回概念卡看适用条件 |
| **结构** | 「逆向问」级变式错 | 练「给结果求条件」 |
| **表达** | 几何说理题漏步 | 采分点自评 |

四维与变式三级几乎同构（改数字→执行、改条件→条件、逆向→结构），这不是巧合——变式阶梯的设计本意就是测能力，只是原先没被命名为「能力诊断」。

### 数据基础（2026-11-24 补齐）

**能力信号来自两套机制，字段不同，必须都认：**

| 机制 | 字段 | 覆盖 | 说明 |
|---|---|---|---|
| 方法卡变式链 | `changed` | 69 题 / 22 族 | 母题 + 3 级变式，方法卡页用 |
| 变式阶梯 | `ladder` + `level` | 42 题 / 16 族 | 锚定真题考点族，阶梯页用 |

两者零交集，所以能力诊断的取数逻辑是 `q.changed || q.level`。

**本轮补齐的 7 条阶梯**（原先这些族没有变式，能力诊断会退化成只看对错）：

| 阶梯 | 锚定族 | 年均分 | 为什么补 |
|---|---|---|---|
| `lad-scinot` 科学记数法 | f-scinot | 3 | 4/4 年年年考，全是送分题 |
| `lad-dms` 角度换算 | f-dms | 1 | 专考 60 进位，错一次整题 0 分 |
| `lad-modelexpr` 列代数式建模 | f-model-expr | 1.5 | 3/4 年考，考的是翻译不是算 |
| `lad-inverse` 反比例 | f-inverse | 0.5 | 判据只有乘积定值，但题干藏得深 |
| `lad-read` 阅读理解 | f-read | 1.5 | 6 分解答题，规则读错全错 |
| `lad-draw` 尺规作图 | f-construct | 6 | **4/4 年年年考，原阶梯锚定错了** |
| `lad-reason` 角度推理 | f-anglereason | 4.8 | **3/4 年考，原阶梯锚定错了** |

**同时修正了两条锚定错位的阶梯**：`lad-segcalc`（原 `lad-construct`）的题目是线段计算，却锚定在「尺规作图」族；`lad-anglesum`（原 `lad-angle`）的题目是算角度，却锚定在「推理说理」族。练的是 A、判的是 B，会让族达标判定失效。

### 覆盖现状与边界

- **能力信号覆盖 26/27 族**。缺的是 `f-eqconcept`（方程概念辨析）——13 题全是单步判断，结构上产不出三级能力信号，合理。
- **三级齐全 23/27 族**。不齐的 3 族是原有方法卡变式链不完整，不影响阶梯使用。
- **推不出的**：表达能力只能从几何说理题算（6 道），样本长期偏少；四维的独立性未验证，若实测发现「执行」与「结构」总是同向变动，应合并。

## 学习页（`learn.html`）

三块材料一处看，**每条末尾都能直接进练习**。结构是**三级下钻**：

```
模块（概念 50 / 公式 46 / 知识点 43）
  └─ 章节目录（6 张卡，各显示条数）
       └─ 章内条目（折叠卡，8 条/页分页）
            └─ 测这张卡 / 练这一族 N 题
```

| 模块 | 条目 | 折叠时看到 | 展开后看到 | 练习入口 |
|---|---|---|---|---|
| **概念** | 50 张卡 | 主张 + 必记首条（TeX 转纯文本）+ 判断数/陷阱数 | 全部必记条件 + 属族 + 入口 | `测这张卡` · `练这一族 N 题` |
| **公式** | 46 条 | 名称 + 适用条件 | 公式（MathJax）+ 误用 + 属族 | `练这一族 N 题` |
| **知识点** | 43 个考点 | 考点 + 累计分 + 出现年数 | 题位 + 属族 | `练这一族 N 题` |

### 为什么要三级下钻

139 个条目全铺开有 **19292px** 高，进来只看到「很长」，看不到「这门课有几块、我在哪」。
加目录层后首屏降到 **1328px**：先给全貌（6 章各多少条），再进去看细节。

章内还要分页是因为单章仍可能超一屏：知识点第 6 章 13 条、公式第 5 章 11 条。
所以按 8 条/页分，不足 8 条的章不显示分页器（现在 18 个章里 7 个有分页器）。

条目折叠同理：全展开一条约 139px，一屏只看 5–6 条；折叠后标题 + 一行摘要约 80px。

### 摘要为什么是「TeX 转纯文本」

必记条件多为数学式（如 `$|a|\ge0$`）。三种处理都不合适：
- 直接渲染 SVG → 摘要和正文各一份，多占约 60KB
- 剥掉 TeX 命令 → `\ge` 被当命令删掉，得到 `|a|0`（失真，比原文更糟）
- 显示原始 LaTeX → 初中生读不了

所以 `texToPlain()` 做一张最小符号表（`\ge→≥`、`\times→×`、`\angle→∠` 等），
把命令换成符号而非删除。表外命令原样保留——宁可留着也不删掉造成语义错误。

### 「关联到题目」是怎么做到的（不需要给 382 题逐题打标签）

题目没有 `concept` / `formula` 字段，但有 `family`（考点族）。而：

- `FAMILY_ASSETS` 已把 **50 张概念卡、46 条公式各恰好归入一个考点族**（`validate.mjs` 第 9 节守着）
- **27 个族全部有站内题**（`Q_BY_FAMILY` 无空族）
- **43 个真题知识点全部归族**

所以「概念 → 族 → 题」这条链每一步都有保证。反查表在 `src/index.js` 的
`CONCEPT_TO_FAMILY` / `FORMULA_TO_FAMILY`，从 `FAMILY_ASSETS` 反转生成，零新增数据。

### 诚实边界（写在页面上）

- **关联是族级的，不是逐题精确的**。「练这一族 N 题」进的是该族**全部**题，不是「只考这张卡的几道题」。
- **知识点用的是真题考点，不是教材目录**。来自 4 份区统考卷的逐题标注，分值是 4 年累计分。
- 知识点排序**先按出现年数、再按分值**——只按分值排会把「新定义 14 分 / 2 年」排在「数轴读符号 12 分 / 4 年」之前，与「先练年年考的」相反。

### 校验（`tools/validate.mjs` 第 10 节，8 条）

数据层：反查表不丢项、每条都能到「有题的族」、模块计数一致。
结构层：目录卡数 = 各模块章数之和、章容器数对得上、每个条目落在章容器内、有条目的章都有容器。
产物层：条目 139 = 练习入口 139、概念卡 50 = 「测这张卡」50。

### e2e（`tools/e2e-core.mjs`，10 项）

初始停在目录 → 点目录进章 → 章内 8 条分页 → 翻页换批 → 返回目录 →
切模块回目录 → 每条都能进练习 → 条目默认折叠可展开 → 返回按钮未被吸顶头部遮挡。

> 「返回按钮未被遮挡」这项是被真实 bug 逼出来的：`scrollIntoView` 会把面包屑
> 顶到 sticky 头部（65px）底下，返回按钮点不到。修法是给 `.learn-crumb` 加
> `scroll-margin-top: 80px`。

## 「像真题」的三个层次

整卷模考（`exam.html`）的目标不是「随机抽 26 题」，是「像真题」。三层标准，缺一层就不像：

1. **卷面结构像** —— 26 题 / 8 选择 + 8 填空 + 10 解答 + 2 选做 / 100+10 分 / 100 分钟。
2. **考点位置像** —— 第 2 题科学记数法、第 17 题混合运算 4 小问（19 分）、第 20 题解方程 2 小问（12 分）、第 23/24 题动态几何压轴、第 26 题新定义。四份真题这些位置**没变过**，组卷也不动。
3. **图表位置像** —— 该配图的地方配图，配图类型也对得上。**这一层最容易被忽略，也最影响「像不像」**：题干不配图，学生第一眼就知道这不是真题。

> 早期版本有一份静态预生成的「同构模拟卷」（`mock.html`，537KB），逐位照抄真题卷面。后因与 `exam.html` 定位重叠、且维护两份成本高而删除，标准合并进 `exam.html` 的组卷逻辑。

### 洞察层的写法约定

洞察不是「再换个说法讲统计」，而是从数据推出可执行的判断。为避免把推断写成事实，**每条都标了来源**：

| 标签 | 含义 | 本页实例 |
|---|---|---|
| **事实** | 可直接从逐题数据算出 | 前 4 个族占 46%；2 分小题 48 道共 96 分；「中档」横跨 2–19 分 |
| **推断** | 由事实推出，但依赖「明年延续」假设 | 目标分倒推；P0–P4 优先级；时间配比 |
| **边界** | 这份材料支撑不了的结论 | 推不出明年考什么；推不出本校难度；推不出该丢哪些分 |

**五条洞察**：
1. 分数集中度——前 4 族占 46%，前 8 族占 67%，共 27 族 → 不是均匀覆盖，是几处重仓
2. 小题 vs 大题——2 分小题（32%，失分机制是「想不起来」）vs 6–19 分大题（68%，失分机制是「一步错全题废」）
3. 「中档」标签的陷阱——同标签横跨 2 分到 19 分，把 20 道小题（40 分）和 6 道大题（89 分）混成一类
4. 目标分倒推——非压轴四段全对天花板只有 86.9 分，要上 90 必须从压轴拿分
5. 难度不是均匀爬升——前 16 题里每年都有 4–6 分硬题，且无部分分

**一条边界**（写进页面，避免过度承诺）：3 份卷子推不出「明年考什么」、推不出「本校难度」（都是区统考卷）、推不出「该丢哪些分」（需实测基线）。

### 跨年整体分析的三个关键量化结论

| 结论 | 数据 | 含义 |
|---|---|---|
| **骨架零变化** | 题量 26 / 100 分钟 / 100+10 分 / 16+16+68 分题型，三年完全一致 | 按任一年组卷都安全，不用赌结构 |
| **题位一致率远低于考点族一致率** | 题位 23%/35%/27% vs 考点族 78%/52%/68% | 押题号必输，押考法才有效——这是「考点族」这一层存在的实证理由 |
| **14 个核心族吃掉 80% 分数** | 239/300 分；外围 13 族仅 61 分 | 核心按最严一年练到零失误，外围广覆盖不深挖 |

### 为什么需要「考点族」这一层

原始逐题标注会因题干换说法被拆散，导致**把「年年考」误判成「偶考」**。真实例子：

```
尺规作图  2021#19「方位角与作图」 / 2022#18「尺规作图与说理」/ 2024#19 同
          → 按原始标注看，每行都像「只考过一次」
          → 按考点族归并后：6 / 6 / 6 分，年年固定 6 分
```

所以频率结论只看 ④，不看 ⑤。归并由 `FAMILY_DEFS` 显式声明 topic 归属，
`tools/validate.mjs` 断言三件事：① 每个必做 topic 恰好属于一族；
② 族分值合计 = 三卷必做总分 300；③ 必考点必须真是三年全考（否则报错）。

> 这条断言是被真实错误逼出来的：曾手写「角度换算每年必考」「四舍五入每年必考」，
> 但 2024-25 卷填空题既无度分秒换算也无四舍五入，实际只有 2/3 年。现已修正并纳入校验。

### 统计一致性由校验器强制保证

`tools/validate.mjs` 里有一组检查（第 8b 节），**这是被真实教训逼出来的**：

我第一版把难度分布**手写**成 32/46/14/8，但按逐题标注实际算出来是 **13/67/9/11**——基础题差了 19 个百分点。

所以现在强制校验：

1. 每卷的章节/能力/难度/题型四套维度之和都必须等于必做总分
2. 所有汇总值必须等于从逐题数据重算的结果
3. 每题必须有 `topic`（知识点细分），否则知识点表会漏
4. 难度标注必须合法
5. 必考点必须在覆盖度表里登记

**教训**：汇总数字不能手写，必须从逐题数据派生。否则「展示值」与「数据」会悄悄脱节。

## 技术要点（踩过的坑）

1. **分片必须自带字形 defs**。动态加载的页面本身没有字形定义，不注入的话公式会全部不可见。
2. **不能快照 `window.YZ.CH`**。分片异步加载，闭包快照会永远指向空对象。
3. **`loadAll` 之后统一注入 defs**，不要在每处 `collect()` 里各写一遍。
4. **公式 SVG 的可见性要用尺寸验证**，不能只看 `innerText`——SVG 没有文本节点。
5. **`export { X as Y }` 不创建本地绑定**。`STATS` 里引用 `QUESTIONS` 会报未定义，必须用 `const`。
6. **`file://` 下只有 classic script 可用**，ES module 会被拦。
7. **多层括号由内向外去**，每层都检查符号——这是初一最高频的失分点。

## 已知限制（诚实边界）

- **不做解答题自动批改**。几何证明与开放性解答无法可靠机器判分，走采分点自评。
- **不接符号计算库**。与 `file://` 断网可开的约束冲突。
- **不做动态几何**。图形构建期渲染成静态 SVG。
- **不宣称押题**。题目按校内命题范围与课标编写，风格贴近本校卷，但不宣称命中具体题目。
- **题量未达规划目标**。当前 248 题，规划目标 400+；计算专项 70 题（目标 120–140）。内容产能是最大风险，按 PLAN.md 的阶段推进。
- **作图题只判「步骤 + 说理」，不判「画得像不像」**。图形是构建期静态渲染，无法判作图痕迹。但这恰好对应真题的真实给分点——真题作图题的分在「说理填空」，不在画功。
- **第六章可开关**。若期末不含几何图形初步，删除 `src/index.js` 里 `GEO_QUESTIONS` 的引入即可，其余部分自动跟随。
- 学习记录存 `localStorage`（`yz-` 前缀），换设备需在「内容说明」页导出档案。
